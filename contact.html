Questions

What a reader usually asks

What was the site built with?

Hand-written HTML5 plus one external CSS file. No JavaScript, no framework, no site generator, no template.

Why is the first file called index.html?

Because a server looks for that file by default when no filename is given. It is the front door of the site.

Does it work on a phone?

Yes. There is a viewport meta tag and two media queries at 940px and 700px: three columns become two, then one, and the navigation is allowed to wrap.

Where do the images come from?

Three diagrams drawn as SVG by me, stored in images/. Small files, sharp at any size, and no licensing questions.

What would you improve next?

More content first — a real project page instead of a placeholder. Later, once JavaScript is on the menu, search and filtering.
